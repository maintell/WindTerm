# 08 · 功能规格 · 远程桌面（RDP / VNC）

承接需求：`GUI-015`~`GUI-035`、`SES-005`、`SES-006`
**已移除**：`GUI-001`~`GUI-014`（X11 / X Server / XDMCP）与 `SES-007`，见 `spec/04` §12.6 与 ADR-0012。

## 1. 范围与技术难点

本域只覆盖**两类远程桌面协议**：RDP（Windows）与 VNC（跨平台通用）。两者都是「像素流 + 输入事件」模型，与终端（字符流）在架构上完全不同。

### 1.1 为什么不做 X11

这是本规格中唯一一处「主动放弃 MobaXterm 的招牌能力」，必须写清理由，否则后来者会以为是遗漏：

| 维度 | 说明 |
|---|---|
| **依赖** | X11 转发必须有本地 X Server。Windows 要装 VcXsrv、macOS 要装 XQuartz、Linux 要用系统 Xorg——三者都是**外部程序**，不是我们能打包的东西（GPL + 体积 + 驱动级兼容） |
| **体验不可控** | rootless 多窗口、扩展支持、OpenGL 加速、中文输入法，质量全部由第三方 X Server 决定。用户遇到问题时，我们既不能修也不能保证 |
| **定位冲突** | 「跨平台、开箱即用、零外部依赖」是本产品的三个前提（`spec/01` §2.4）。X11 与三者同时冲突 |
| **收益递减** | 现代 Linux 服务器上需要跑图形程序的场景（Oracle 安装器、老式 CAD）占比很低，且用户已经知道 `ssh -X` |

**用户的替代路径**（必须在文档与 FAQ 中给出）：在本地自装 X Server，然后 `ssh -X user@host` 到目标机——这条路径与我们无关，也不需要我们参与。WindTerm 的定位是「把不需要外部依赖的那 90% 做好」，而不是「什么都做但都不牢」。

**决策记录**：ADR-0012。作废的 15 条需求保留 ID 与理由（`spec/04` §12.6）。

### 1.2 本域明确不做的四项

| 需求 | 内容 | 理由 |
|---|---|---|
| `GUI-027` | RDP RemoteApp（只发布单个应用） | 需服务端 RemoteApp 配置，使用面极窄；IronRDP 支持度不足 |
| `GUI-032` | 远程桌面会话录制 | 视频编码与存储负担大，且录制他人桌面有合规风险。用户可用系统级录屏工具 |
| （原 `GUI-001`~`014`） | X11 转发 / X Server / XDMCP | 见 §1.1、ADR-0012 |
| （原 `SES-007`） | XDMCP 会话类型 | XDMCP 依赖 X Server，随 X11 一并移除 |

### 1.3 两个真实难点

**难点一：画面能显示不等于能用。**
键盘布局（扫描码 vs 虚拟键）、输入法（组合过程）、剪贴板格式（文本/图片/文件）、多显示器、动态分辨率、DPI 缩放——每一项都能让「看起来能用」变成「实际不能用」。MobaXterm 的 RDP 之所以好用，是这些细节都调过。

**难点二：VNC 的编码与认证碎片化。**
RFB 只有 3.8 是标准，但市面上的服务端在 3.3/3.7/3.8 之间分布，编码支持各不相同（Tight 是私有扩展），认证方式有 8 种以上。规格必须明确「支持哪些、不支持哪些」，而不是笼统写「支持 VNC」。

## 2. RDP

### 2.1 GUI-015 / GUI-023 · 客户端与控制台会话

| 字段 | 值 |
|---|---|
| 优先级 | P0 · 兼容性 C1 |
| 来源 | `F:rdp` `D:4.4` |
| 实现 | `IronRDP`（Devolutions，Apache-2.0/MIT） |

**渲染**：RDP 画面在 Rust 侧解码为 RGBA 位图，通过 IPC 推给前端 canvas 绘制（见 `design/07` §4）。**不使用** HTML `<video>` 或 WebRTC。

**行为**

1. 标签内渲染，自适应窗口大小（发送 `DISPLAYCONTROL_MONITOR_LAYOUT`）。
2. 全屏：独占一个显示器，顶部悬浮工具条（可隐藏）显示「退出全屏 / 发送 Ctrl+Alt+Del / 连接信息」。
3. 断开策略：`断开`（保留会话）/ `注销`（结束会话）/ `关机`（需二次确认）。
4. 控制台会话（`GUI-023`）：在 `SERVER_CORE` 的 `EarlyCapabilityFlags` 中设置 `CONSOLE_SESSION`（等价 `/admin`）。
5. 用户名留空时进入远端登录界面（发送空凭据，走 NTLM 交互式）。

**验收标准**

- [ ] AC-1 连接 Windows Server 2012 R2 / 2016 / 2019 / 2022 均成功
- [ ] AC-2 连接 Windows 10/11 专业版（单会话）成功
- [ ] AC-3 窗口从 1280×720 拉伸到 1920×1080，远端分辨率随之变化且画面不模糊
- [ ] AC-4 全屏下 `Ctrl+Alt+Del` 被本地拦截并提示「请用工具栏按钮发送」

### 2.2 GUI-016 · 增强图形

| 编码 | 支持 | 说明 |
|---|---|---|
| `RawBitmap` | 是 | 基线 |
| `RLE` / `BitmapUpdate` | 是 | |
| `RemoteFX`（Progressive） | 是 | 适合照片/渐变 |
| `EGFX` + `H.264` | 是 | 需 OpenH264 官方二进制（专利授权，`spec/01` §5.3） |
| `EGFX` + `RemoteFX` | 是 | H.264 不可用时的回退 |
| `AVC444` | 是（若 IronRDP 支持）【待验证】 | 文本清晰度更好 |

**设置**：`自动`（优先 EGFX/H.264，失败回退）/ `兼容`（只用 RemoteFX）/ `最低带宽`（只用 RLE）。

**性能预期**（局域网，1080p）：`NFR-005` 要求输入到显示 ≤ 60 ms；视频播放场景 ≥ 25 fps。

### 2.3 GUI-017 / GUI-018 / GUI-019 / GUI-020 · 重定向

**驱动器（`GUI-017`）**

- 选择要重定向的本地盘符或目录；可设只读。
- 远端显示为「网络驱动器」，名称 `WindTerm`（可配）。
- 实现：`RDPDR` 虚拟通道 + `IRP` 处理（`IRP_MJ_CREATE/READ/WRITE/QUERY_DIRECTORY/SET_INFORMATION`）。
- 限制：不支持文件锁语义、不支持 `mmap`，大文件随机读写性能差（UI 需说明「重定向驱动器适合传文件，不适合运行数据库」）。

**剪贴板（`GUI-018`）**

| 格式 | 支持 |
|---|---|
| `CF_UNICODETEXT` | 是 |
| `CF_DIB` / `PNG` | 是（图片） |
| `CF_HDROP`（文件） | 是（走驱动器重定向，不复制内容） |
| `CF_HTML` | 是（保留格式） |
| 自定义格式 | 否 |

方向可配：双向 / 仅本地→远端 / 仅远端→本地。

**打印机（`GUI-019`）**

- 只做「打印到 PDF」虚拟打印机：远端打印时把 XPS/EMF 数据落到本地，转换为 PDF 并保存。
- 真实打印机驱动重定向不做（需要 Windows 打印驱动，跨平台不可行）。

**端口（`GUI-020`）**

- 串口/并口重定向，仅 Windows 宿主有意义。
- 用于远端程序访问本地串口设备（如 POS、PLC）。

### 2.4 GUI-021 · 智能卡

| 平台 | API |
|---|---|
| Windows | `SCardAPI` / `NCrypt`（`CERT_CREDENTIAL_INFO`） |
| macOS | CryptoTokenKit |
| Linux | PC/SC (`libpcsclite`) |

**优先级 P2**：实现成本高（需要 PKCS#11 集成、证书链校验、PIN 缓存），且使用场景集中在政务/金融内网。**M0 只做技术验证，不做产品化**。

### 2.5 GUI-022 / GUI-034 · NLA 与证书校验

**NLA / CredSSP**

```
TCP 连接 → X.224 协商（要求 PROTOCOL_SSL | PROTOCOL_HYBRID）
  → TLS 握手（验证服务端证书）
  → CredSSP：TSRequest(NTLM 协商) → NTLM 认证 → 公钥绑定
  → 进入 RDP 安全通道
```

| 失败情况 | 错误信息 |
|---|---|
| 服务端要求 NLA 但本地关闭 | 「服务器要求网络级身份验证（NLA），请在会话设置中启用 CredSSP」 |
| 证书不受信 | 展示证书详情，要求「本次信任」或「加入信任列表」 |
| NTLM 认证失败 | 翻译 NTSTATUS：`0xC000006D`→用户名或密码错误；`0xC000006A`→密码错误；`0xC0000234`→账号锁定；`0xC0000072`→账号禁用；`0xC000015B`→不允许该登录类型 |
| 时钟偏差导致 Kerberos 失败 | 「客户端与服务器时间相差 N 分钟，Kerberos 要求 ≤ 5 分钟」 |

**证书校验（`GUI-034`）**

- 展示：主体、颁发者、有效期、SHA-256 指纹、是否自签。
- 动作：`取消` / `本次信任` / `加入信任列表`（可在设置中查看与撤销）。
- **不提供**「永久忽略所有证书错误」这种全局开关（这是安全反模式）。

### 2.6 GUI-024 · 多显示器与动态分辨率

- `current`（当前窗口所在屏）/ `all`（全部屏拼接）/ `screen:N`。
- 动态分辨率：窗口尺寸变化 → 去抖 300 ms → 发送新的 `MONITOR_LAYOUT`。
- 缩放：`100%/125%/150%/175%/200%`，影响远端 DPI（`DEVICE_SCALE_FACTOR`）。
- 全屏跨多屏时，任务栏位置与主屏判定遵循 OS 设置。

### 2.7 GUI-025 · 音频重定向

- `RDPSND` 虚拟通道，输出 PCM 到本地音频设备。
- 设置：`本地播放`（默认）/ `远端播放` / `关闭`。
- 音频输入（麦克风）重定向 P3。
- 音频会显著增加带宽，UI 提示「音频会占用额外带宽」。

### 2.8 GUI-026 · 键盘快捷键转发

| 本地按键 | 行为 |
|---|---|
| `Ctrl+Alt+Del` | 本地拦截，提示「请用工具栏按钮发送」或按配置转发 |
| `Ctrl+Alt+End` | 转发为远端的 `Ctrl+Alt+Del` |
| `Alt+Tab` | 默认本地切换；开启「转发快捷键」后发往远端 |
| `Win` 键 | 默认本地；可配转发（远端 Windows 的 `Win` 键） |
| `Ctrl+Shift+Esc` | 转发（远端任务管理器） |

**验收标准**

- [ ] AC-1 开启转发后 `Alt+Tab` 在远端生效，本地窗口不切换
- [ ] AC-2 关闭转发后 `Alt+Tab` 在本地生效
- [ ] AC-3 `Ctrl+Alt+End` 在远端触发安全选项界面

### 2.9 GUI-033 · 会话重连

- 使用 RDP 的 autoreconnect cookie（`ARC_CS_PRIVATE_PACKET`）。
- 网络中断后自动重连（复用 `SES-027` 的重连策略）。
- 重连失败：保留窗口与最后画面（灰化），提供「重试 / 重新登录 / 关闭」。

## 3. VNC

### 3.1 GUI-028 · 客户端

| 字段 | 值 |
|---|---|
| 优先级 | P1 · 兼容性 C1 |
| 协议 | RFB 3.3 / 3.7 / 3.8 |

**编码支持**

| 编码 | 编号 | 优先级 |
|---|---|---|
| Raw | 0 | P0 |
| CopyRect | 1 | P0 |
| RRE | 2 | P1 |
| Hextile | 5 | P0 |
| TRLE | 15 | P1 |
| ZRLE | 16 | P0 |
| Cursor（伪编码） | -239 | P1 |
| DesktopSize（伪编码） | -223 | P1 |
| CursorPos（伪编码） | -232 | P2 |

**行为**

- 标签内渲染；缩放模式：`适应窗口` / `1:1` / `自定义比例`。
- 只读模式（`viewOnly`）：丢弃所有键鼠事件，UI 显示「只读」角标。
- `shared` 标志：允许/拒绝其他客户端同时连接（取决于服务端）。
- 桌面尺寸变化时自适应。

**验收标准**

- [ ] AC-1 连接 TigerVNC / TightVNC / RealVNC / macOS 屏幕共享 / QEMU VNC 五种服务端
- [ ] AC-2 ZRLE 编码下 1080p 静态画面带宽 < 1 Mbps
- [ ] AC-3 只读模式下点击与键入均无效

### 3.2 GUI-029 · 认证

| 安全类型 | 编号 | 支持 |
|---|---|---|
| None | 1 | 是（**红色警告**：无认证） |
| VNC Authentication | 2 | 是（DES 挑战-响应；密码截断为 8 字符，需在 UI 说明） |
| VeNCrypt | 19 | 是 |
| ├ Plain | 256 | 是（**仅限 TLS 之上**） |
| ├ TLSNone | 257 | 是 |
| ├ TLSVnc | 258 | 是 |
| └ TLSPlain | 259 | 是 |
| Apple Remote Desktop | 30 | 是（macOS 屏幕共享） |
| RA2 / RA2ne | 5 / 6 | 否（RealVNC 私有） |

**VNC 密码的 8 字符限制**是协议限制，UI 必须在输入框下方说明「VNC 认证只使用密码前 8 个字符」。

### 3.3 GUI-030 · 剪贴板

- 双向文本剪贴板（`ServerCutText` / `ClientCutText`）。
- 大内容截断（1 MB）并提示。
- 可关闭。

### 3.4 GUI-031 · 缩放与自适应

| 模式 | 说明 |
|---|---|
| 适应窗口 | 等比缩放，保持宽高比，留黑边 |
| 1:1 | 原始像素 |
| 自定义 | 50%~400% |
| 平滑 | 双线性（默认）/ 最近邻（像素艺术/文字更锐利） |

## 4. GUI-035 · 图形会话截图

- 一键截取当前图形会话（RDP/VNC 标签）。
- 选项：整个画面 / 选区。
- 输出：复制到剪贴板 / 保存 PNG。
- 快捷键 `Ctrl+Shift+Alt+S`。

> 原「当前窗口（X11）」选项随 X11 移除。

## 5. 异常与边界

| 情况 | 期望行为 |
|---|---|
| RDP 服务端主动断开 | 显示断开原因（`SERVER_DISCONNECT` 的错误码翻译） |
| RDP 画面解码失败 | 跳过该帧，请求关键帧刷新；连续 10 次失败则重连 |
| VNC 服务端不支持任何共同编码 | 报错并列出双方支持的编码 |
| 剪贴板循环 | 哈希去重 + 200 ms 时间窗抑制 |
| 输入法组合期间窗口失焦 | 取消组合，不发送半成品字符 |
| 高 DPI（200%）下 RDP 画面模糊 | 使用 `DEVICE_SCALE_FACTOR` 请求远端按缩放渲染；不支持时用最近邻放大并提示 |
| 用户仍想用 X11 | 文档与 FAQ 指向「自装 X Server + `ssh -X`」，不在产品内提供任何入口 |
