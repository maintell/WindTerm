# 02 会话与会话树

## 会话从哪来

两条路：**手工新建**（左侧「新建会话」）或**从 MobaXterm 导入**（「导入」按钮，或命令行 `wt session import --file MobaXterm.ini`）。

导入会把 MobaXterm 的文件夹结构还原成会话树，重名会按「名字+主机+端口」去重，重复导入不会长出一堆副本。**密码不会导入**——MobaXterm 的密码是它自己的主密码加密的，读不了；导入后需要重新输入或存进保险库。

## 会话树能做什么

| 动作 | 怎么做 |
|---|---|
| 连接 | 点会话名（自动填表单）→ 点「连接 SSH」 |
| 折叠文件夹 | 点文件夹名；状态会存下来，下次打开还是这个形状 |
| 移动/排序 | 拖到文件夹上＝移进去；拖到另一条会话上＝排到它前面；拖到空白处＝移回根 |
| 右键菜单 | 重命名 / 复制 / 移动到… / 导出（JSON） |
| 过滤 | 顶部过滤框，只留匹配的会话（父文件夹会保留，方便看上下文） |
| 删除 | 工具栏「删除」→「确认删除」（两步，防误点） |
| 多选 | `Ctrl+点击` 增减选中；选中多个后右键 →「移动 N 项到…」或「删除 N 项…」 |

## 跳板机（含多跳）

勾「经跳板机」，填跳板机的主机/用户/密码，再连目标。

三件要清楚的事：

1. **跳板机的凭据不继承目标机的**。跳板机和目标机往往是两套账号，界面要求分别填。
2. **多跳靠会话属性实现**：把 A 的跳板设成 B、B 的跳板设成 C，连接时只选「B」，实际就是 A←B←C 三跳。跳板会话各自的密码分别存在保险库里。
3. **错误带跳号**：`第 2 跳（bastion2:22）` 这种前缀，说明是哪一段出的问题，不用一台台试。

> 手填的跳板机只有一跳；多跳要配成会话链。上限 5 跳。

**跳板机连接会被复用**：同一台跳板机、同一套密码，第二条连接只在已有的那条 SSH 会话上新开一条通道，不会在跳板机上再登一次——开一堆标签时，跳板机的 `ss` 里不会堆出一排登录。跳板机重启或链路断了的话，下次连接会自动重登（缓存里那条坏连接会被摘掉）。目前只对**手填的单跳**生效，多跳链每次重连。

## 会话属性

点会话时自动带出的东西：主机、端口、用户名、跳板机。这些存在会话库里，改一次以后都生效。

密码不在这里——密码在保险库（见 [06 安全](06-security.md)）里按会话单独存。
