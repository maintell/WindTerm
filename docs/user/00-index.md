## 三条通用约定

1. **错误都有稳定错误码**（形如 `[SSH_AUTH_FAILED]`），界面与命令行说的是同一套。搜错误码比搜整句话快。
2. **不确定的东西会明说**：主机密钥没验证、配置没保存、编码猜不出来时，界面会直接讲，不会假装成功。
3. **数据都在一个目录里**：会话库（`data.db`）、偏好（`config.toml`）、`known_hosts`、保险库（`vault.wtvlt`）同在数据目录下，默认 `%APPDATA%\WindTerm`，可用 `--config-dir` 改。
