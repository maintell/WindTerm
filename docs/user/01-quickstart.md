# 01 快速开始

## 打开第一个终端

1. 启动 WindTerm，点左侧的「新建本地终端」。
2. 你会得到一个本机的 shell（PowerShell / cmd，取决于系统配置）。

这条路径不需要任何配置，用来确认「应用本身是好的」。

## 连一台远程机器

左侧表单填四项：**主机、端口（默认 22）、用户名、密码**，点「连接 SSH」。

连上后有三件事值得知道：

- **首次连接会记录主机密钥**（TOFU）。状态栏会提示「已记录指纹」，之后同一台机器再连就是安静的。
- **主机密钥变了会被拒绝**，并显示新旧指纹。这不是 bug——要么机器重装了，要么有人在中间。确认后再重置信任（见 [06 安全](06-security.md)）。
- **密码可以不保存**。要保存就走保险库（见下）。

## 三种认证方式

| 方式 | 什么时候用 | 怎么填 |
|---|---|---|
| 密码 | 临时机器、<br>测试环境 | 直接填密码；勾「记住密码」需要先有保险库 |
| 私钥 | 生产环境（推荐） | 勾「用密钥」，选文件。支持 OpenSSH 新旧格式、PEM、PuTTY `.ppk`（未加密） |
| ssh-agent | 私钥不出 agent（更安全） | 勾「用 agent」。Windows 上要先开「OpenSSH Authentication Agent」服务或用 Pageant |

三选一是**互斥**的：勾了密钥，密码框会收起；勾了 agent，前两个都会收起。

## 设置在哪

**左侧会话树顶部的「设置」**——它与会话无关，一个终端都没开也能进去（改编码、字体、语言都在这里）。开着会话时终端底栏也有一个同样的「设置」，两个入口打开的是同一个面板。

设置里有搜索框：按名字或中英文关键词过滤（`gbk`、`乱码`、`encoding` 都能命中），**回车会跳到第一个命中项**并把焦点给它。

每项都标了**生效范围**、**默认值**和**是否需要重启**。

## 界面语言

设置 → 常规 → 「界面语言」可切中文 / English，立刻生效并写进 `config.toml`。

> 目前覆盖标了 `data-i18n` 的元素（主按钮、设置项名、对话框标题与按钮，44 个键 / 47 处）和状态栏里那批固定提示语（37 条）；错误消息、右键菜单、以及状态栏里带变量的那种提示仍是中文。**没覆盖到的地方仍是中文，不是漏翻就是还没做**。

## 连不上时先看这个

| 现象 | 先查什么 |
|---|---|
| `[SSH_CONNECT_FAILED]` | 主机/端口是否可达（`ping`、`telnet host 22`） |
| `[SSH_AUTH_FAILED]` | 用户名对不对、密码是否过期、服务端是否禁用了密码认证 |
| `[SSH_HOSTKEY_UNKNOWN]` | 没确认过指纹；看提示里显示的指纹是否与服务器管理员给的一致 |
| 一直转圈 | 多半是网络黑洞（防火墙丢包），不是应用卡死 |

完整的错误码映射见 [07 排查](07-troubleshooting.md)。
