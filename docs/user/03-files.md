# 03 文件传输

## 打开文件面板

连上 SSH 后点左侧「文件」，面板会列出远端当前目录。

面板顶部有一个**「对着哪台机器」**的下拉：

- 「跟随连接表单」：用表单里的主机/用户（改端口会立刻影响它）；
- 选某个会话：用那个会话的参数，**每个会话各自记住浏览位置**。

## 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 进目录 / 下载 | 双击（目录进入，文件下载） |
| 上传 | 拖文件进面板，或点「上传」选择文件 |
| 新建目录 | 「+ 目录」 |
| 改名 | 选中一项 →「改名」 |
| 删除 | 选中 →「删除」→「确认删除」；非空目录会由服务端拒绝并说明原因 |
| 大文件 | 上传是分块的（64 KB 一块），进度来自真实写入，不是假设 |

同名下载**不会覆盖**：会自动变成 `notes (1).txt`。

## 编辑远端文件

选中文件 →「编辑」：先把远端文件下载到本地（`下载目录/wt-edit/`），然后二选一：

1. **用系统程序打开** —— 用你惯用的编辑器改，改完回到对话框点「写回远端」；
2. **在内嵌编辑器打开** —— 应用内改（多标签、行号、查找替换含正则、`Ctrl+S` 保存）。

写回前会**比一次远端大小**：这期间如果有人改过这个文件，会报 `[SFTP_CONFLICT]` 拒绝覆盖——悄悄盖掉别人的修改是最坏的行为。文件被删了也不会自动重建。

内嵌编辑器的边界：**只收 UTF-8、单文件上限 2 MB**，超了会明确拒绝并建议用外部编辑器（不猜编码，也不假装能打开）。

## 拖出去下载

不支持。WebView2 里 `DownloadURL` 只支持 http/data URL，真要拖出需要额外插件。用双击下载。
