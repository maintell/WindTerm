# 03 文件传输

## 打开文件面板

连上 SSH 后点左侧「文件」，面板会列出远端当前目录。

面板顶部有一个**「对着哪台机器」**的下拉：

- 「跟随连接表单」：用表单里的主机/用户（改端口会立刻影响它）；
- 选某个会话：用那个会话的参数，**每个会话各自记住浏览位置**。

## 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 进目录 / 下载 | 双击（目录进入，文件下载） |
| 上传 | 拖文件进面板，或点「上传」选择文件 |
| 新建目录 | 「+ 目录」 |
| 改名 | 选中一项 →「改名」 |
| 删除 | 选中 →「删除」→「确认删除」；非空目录会由服务端拒绝并说明原因 |
| 大文件 | 上传是分块的（64 KB 一块），进度来自真实写入，不是假设 |

列表上方有**列头**（名称 / 大小 / 权限 / 修改时间），点一下按那一列排序，再点一次翻转方向；
到「设置 → 文件 → 显示列」可以把「大小」「权限」「时间」单独关掉（名称始终显示），表头会跟着收起。
「时间」默认**不显示**：文件面板在左侧栏，名称 + 大小 + 权限已经占满一行，再加一列时间会把文件名挤到几乎看不见——需要的时候勾上就行。
服务端没给修改时间时那一格留空，不填一个假的时间。属主（owner）SFTP 列不出来，所以没有这一列。
目录始终排在最前面。默认顺序是「目录在前 + 名称升序」。

同名下载**不会覆盖**：会自动变成 `notes (1).txt`。

## 右键菜单

在文件行上点右键，只会列出「这个对象能做什么」：

- 目录：「打开」「新建文件夹」「重命名」「删除」「权限…」「复制路径」
- 文件：同上，但「打开」换成「用编辑器打开」，另加「下载」
- 空白处右键：只给「新建文件夹」——把需要对象的动作也列出来等于骗人

「删除」会弹确认框（不做递归删除，非空目录由服务端拒绝并说明原因）；「权限…」输八进制，类型位原样保留。

以 `.` 开头的隐藏文件**默认显示**（运维场景 `.env`、`.gitignore` 必须能看到）。要藏起来，
到「设置 → 文件 → 显示隐藏文件」关掉；切换只是过滤列表，不会重新连服务端。

## 编辑远端文件

选中文件 →「编辑」：先把远端文件下载到本地（`下载目录/wt-edit/`），然后二选一：

1. **用系统程序打开** —— 用你惯用的编辑器改，改完回到对话框点「写回远端」；
2. **在内嵌编辑器打开** —— 应用内改（多标签、行号、查找替换含正则、`Ctrl+S` 保存）。

写回前会**比一次远端大小**：这期间如果有人改过这个文件，会报 `[SFTP_CONFLICT]` 拒绝覆盖——悄悄盖掉别人的修改是最坏的行为。文件被删了也不会自动重建。

内嵌编辑器的边界：**只收 UTF-8、单文件上限 2 MB**，超了会明确拒绝并建议用外部编辑器（不猜编码，也不假装能打开）。

## 路径：面包屑与直接输入

面板顶部的路径是**面包屑**：`/ › sub › deep`，点其中任意一段就跳到那一层。
想直接去某个目录，点「路径…」输入完整路径再按回车；输入 `~` 会由服务端解析成 home 目录
（SFTP 没有 shell，前端不猜）。按 `Esc` 取消输入，当前目录不变。相对路径按当前目录补全。

## 侧栏目录树

面板上方是**只列目录**的树：点 `▸` 展开（展开时才去读那一层），点目录名让列表进那一层，当前所在目录会高亮。刷新按钮连同树一起重建。文件已经在右侧列表里，树里不再重复放一遍。

「⟳」是手动刷新。到「设置 → 文件 → 自动刷新间隔」可以设成 5/15/30/60 秒：窗口重新获得焦点、且距上次列目录已超过这个间隔时，自动刷新一次目录与树；默认**关闭**（焦点事件很频繁，不节流会反复连服务端）。窗口不活跃时不会发任何请求。

## 权限与符号链接

- 每行有一列权限位（`-rw-r--r--`，链接以 `l` 开头）；
- 选中后点「权限」可以改（八进制，如 `644`）。**类型位会原样保留**，不会把文件改成未知类型；
- 符号链接显示成 `name@`，目标在 tooltip 里；**断链**用颜色与删除线标出来，不会到最后一步才报错；
- 目录没权限时显示明确的 `[SFTP_PERMISSION_DENIED] 权限不足：…`，**不会显示成空目录**。

## 大目录

列表是虚拟滚动的：1000 个条目只渲染看得见的那几十行，滚动时窗口跟着走。

## 拖出去下载

不支持。WebView2 里 `DownloadURL` 只支持 http/data URL，真要拖出需要额外插件。用双击下载。
