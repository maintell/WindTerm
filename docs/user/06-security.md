# 06 安全

## 主机密钥校验（TOFU）

第一次连一台机器时，应用会记下它的主机密钥（状态栏提示「已记录指纹」）。之后每次连接都会比对：

- 一致 → 安静通过；
- **变了 → 拒绝连接**，并显示新旧指纹。

变了不一定是攻击：重装系统、换机器、负载均衡后面挂了另一台都会变。确认确实是对方变了之后，去**设置 → 已知主机**找到那一条点「忘记」——下次连接它会重新走一次 TOFU 确认。

`known_hosts` 用的是 OpenSSH 格式，位置在数据目录下，可以和应用外的工具共用。

## 保险库与主密码

要用「记住密码」就必须有保险库：

1. 勾「记住密码」→ 设置**主密码**（这个主密码不存盘，忘了就解不开）；
2. 主密码用 Argon2id 派生出密钥，保险库文件用 XChaCha20-Poly1305 加密，文件头是 `WTVLT`；
3. 连接成功后密码按会话存进保险库；再点该会话会自动填入。

**主密码不在内存里长期驻留**：应用重启后需要重新解锁。这也是「冷启动自动拉起隧道」还没做的原因（见下）。

## 密码不保存也能用

不勾「记住密码」时，密码只存在于当前会话内存里，关掉就没了。敏感环境建议这样用。

## 生成密钥

底部「密钥」：

- 支持 **ed25519 / RSA 3072 / ECDSA P-256**，可设口令加密；
- 生成后给出 SHA256 指纹、可贴进 `authorized_keys` 的公钥行、私钥落盘路径（下载目录）；
- 「导入已有密钥」只看算法与指纹——**私钥内容不会回传界面**。

## 已知的安全取舍

| 取舍 | 原因 |
|---|---|
| 带 SOCKS5 认证的隧道不保存配置 | 口令不写进配置文件；代价是重启后要重填 |
| 主密码不托管 | 想要「冷启动自动拉起隧道」就得把主密码存下来，这个取舍还没定 |
| 右键粘贴不启用 | 需要 Rust 侧读剪贴板，会引入 X11 客户端依赖（与「零 X11 依赖」冲突），未定 |
