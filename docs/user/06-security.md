# 06 安全

## 主机密钥校验（TOFU）

第一次连一台机器时，应用会记下它的主机密钥（状态栏提示「已记录指纹」）。之后每次连接都会比对：

- 一致 → 安静通过；
- **变了 → 拒绝连接**，并显示新旧指纹。

变了不一定是攻击：重装系统、换机器、负载均衡后面挂了另一台都会变。确认确实是对方变了之后，去**设置 → 已知主机**找到那一条点「忘记」——下次连接它会重新走一次 TOFU 确认。

`known_hosts` 用的是 OpenSSH 格式，位置在数据目录下，可以和应用外的工具共用。

## 保险库与主密码

连接表单里的「密码」是三选一，不是勾选框：

| 选项 | 密码放哪 | 代价 |
|---|---|---|
| **不记住** | 只在本次连接的内存里 | 关掉就没了，下次要重输 |
| **本次记住** | 只在本次运行的内存里 | 不落盘、不要主密码；退出应用就忘 |
| **永久记住** | 保险库（加密文件） | 需要先设**主密码** |

选「永久记住」时才有保险库：主密码用 Argon2id 派生出密钥，保险库文件用 XChaCha20-Poly1305 加密，文件头是 `WTVLT`。连接成功后密码按会话存进保险库；再点该会话会自动填入。

**新建连接时的初值可以改**：设置 → 安全 → 「密码保存默认值」。改它只影响表单初值，不会删掉已经存进保险库的口令。

**主密码在解锁期间会留在内存里**（用 zeroize 包着，锁定或退出进程即清）：保存凭据、改密码、轮换密钥都要用它重新封装，每次重新输入并不现实。应用重启后需要重新解锁。这也是「冷启动自动拉起隧道」还没做的原因（见下）。

### 换主密码 / 移除保险库

**设置 → 主密码**。改密码要输旧密码（它会被用来验一次），**保险库里的密码一条都不会丢**。

**设置 → 轮换加密密钥**：换一个新的 salt 把整份保险库重新加密一遍——条目不变、主密码不变。
什么时候该做：怀疑有旧的密钥材料在别处泄漏过（备份、截图、旧机器）时。轮换会覆盖磁盘上的密文，
旧文件不再保留，所以会先弹一次确认。

「移除保险库」会把文件删掉、里面的密码全部消失且**无法恢复**，确认框里会明说。移除后「永久记住」回到未创建状态。

## 密码不保存也能用

选「不记住」或「本次记住」都不需要保险库，密码只存在于内存里，关掉应用就没了。敏感环境建议这样用。

## 生成密钥

底部「密钥」：

- 支持 **ed25519 / RSA 3072 / ECDSA P-256**，可设口令加密；
- 生成后给出 SHA256 指纹、可贴进 `authorized_keys` 的公钥行、私钥落盘路径（下载目录）；
- 「导入已有密钥」只看算法与指纹——**私钥内容不会回传界面**。

## 已知的安全取舍

| 取舍 | 原因 |
|---|---|
| 带 SOCKS5 认证的隧道不保存配置 | 口令不写进配置文件；代价是重启后要重填 |
| 主密码不托管 | 想要「冷启动自动拉起隧道」就得把主密码存下来，这个取舍还没定 |
| 右键粘贴不启用 | 需要 Rust 侧读剪贴板，会引入 X11 客户端依赖（与「零 X11 依赖」冲突），未定 |
