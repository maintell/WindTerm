# 05 终端

## 编码

底栏「设置」→「终端编码」，可切 **UTF-8 / GBK / GB18030 / Big5 / Shift-JIS / Latin-1**。

- 切换**只影响之后的输出**，已经显示的内容不动（不用为了改编码把历史刷掉）；
- 看到乱码先切 GBK 试试——这是中文环境最常见的情况；
- 编码选择保存在 `config.toml` 里。

## 外观

同一个设置面板里：**配色（21 套，可导入）/ 字体 / 字号 / 行高 / 回滚行数**（默认 1 万行，可到 100 万）。

配色支持导入：Windows Terminal 的 `schemes` JSON 与 iTerm2 的 `.itermcolors`，粘贴文本或选文件都行。导入的方案存在 `config.toml` 里，重启后还在；同名会覆盖而不是越攒越多。搜索框支持中英文关键词（搜「乱码」能直接定位到编码）。改完立刻作用于所有已打开的会话，并重新计算行列数（远端 `stty size` 会跟着变）。

偏好写在 `config.toml`，可以进 Git 做版本管理。

## 剪贴板

| 动作 | 快捷键 |
|---|---|
| 选中即复制 | 默认开启（双击选词、拖选） |
| 复制 | `Ctrl+Shift+C` / `Ctrl+Insert` |
| 粘贴 | `Ctrl+Shift+V` / `Shift+Insert` |

- `Ctrl+C` **保留给中断信号**，不会变成复制——这是肌肉记忆，不能改；
- 多行粘贴会先弹确认并显示前几行，取消后一个字节都不发；
- 远端开启 bracketed paste（`?2004`）时，粘贴会被正确包裹，vim 里不会出现 `200~` 字样；
- 右键 / 中键粘贴可用；万一某个构建里读剪贴板被策略拒绝，会明确提示「请用 `Ctrl+Shift+V`」而不是静默无反应。

## 快捷键可以重绑

底部「键位」→ 每行一个动作 → 点「录制」→ 按新组合键。

- **冲突会被拒绝**，并告诉你被哪个动作占用了；
- 可「恢复默认」、**导出成 JSON 文件**、**从文件导入**（不认识的动作用「跳过 N 项」说出来）；
- 目前可重绑 **17 个动作**：复制、查找、查找上/下一个、放大/缩小/重置字号、关闭查找栏、广播、文件面板、隧道面板、新建本地终端、上/下一个标签、打开设置、键位、左右分屏；
- 键位存在 `config.toml`。

## 多执行广播

底部「广播」打开一条输入栏：一条命令发给**所有已连接会话**。

- 两种模式：「一行一发」「发送前确认」；
- 结果按输出分组：一致就折成「N 台一致：…」，不一致的按组展开并标红，悬停看完整输出；
- **危险命令**（`rm -rf /`、`mkfs`、`dd of=/dev/`、`shutdown`、fork 炸弹等）无论哪种模式都强制确认，确认框里写明命令原文与目标会话数；
- **结果可导出 CSV**：表头 `命令,主机,输出`，每台一行；按 RFC 4180 转义并带 UTF-8 BOM，Excel 打开中文不乱码。

## 标签

| 动作 | 怎么做 |
|---|---|
| 关闭 | 点 `×` 或**中键**点标签 |
| 重命名 | **双击**标签 |
| 复制标签 | 右键标签 →「复制标签」（用同一条连接参数再开一个） |
| 关闭其他 / 关闭右侧 / 关闭全部 | 右键标签 |
| 调整顺序 | 按住左键拖动标签 |

标签栏溢出时横向滚动，不会把每个标签压扁。

## 鼠标上报

远端程序（vim、tmux、`htop`）开启鼠标模式后，点击/滚动会作为鼠标序列发给远端；按住 `Shift` 点击则强制本地选择文本，不发给远端。

## 查找

`Ctrl+F` 打开查找栏，输入即搜，计数显示 `x/y`；`Esc` 关闭。
