# 05 终端

## 编码

底栏「设置」→「终端编码」，可切 **UTF-8 / GBK / GB18030 / Big5 / Shift-JIS / Latin-1**。

- 切换**只影响之后的输出**，已经显示的内容不动（不用为了改编码把历史刷掉）；
- 看到乱码先切 GBK 试试——这是中文环境最常见的情况；
- 编码选择保存在 `config.toml` 里。

## 外观

同一个设置面板里：**配色（21 套，可导入）/ 字体 / 字号 / 行高 / 回滚行数**（默认 1 万行，可到 100 万）。

配色支持导入：Windows Terminal 的 `schemes` JSON 与 iTerm2 的 `.itermcolors`，粘贴文本或选文件都行。导入的方案存在 `config.toml` 里，重启后还在；同名会覆盖而不是越攒越多。搜索框支持中英文关键词（搜「乱码」能直接定位到编码）。改完立刻作用于所有已打开的会话，并重新计算行列数（远端 `stty size` 会跟着变）。

偏好写在 `config.toml`，可以进 Git 做版本管理。

## 剪贴板

| 动作 | 快捷键 |
|---|---|
| 选中即复制 | 默认开启（双击选词、拖选）；可在设置里关掉，也可把防抖延迟调到「立即」 |
| 双击选词 | 分隔符可在设置里追加（例如填 `:` 后，`user@host:/var/log` 只会选中 `user@host`） |
| 三击 | 选整行（不含换行） |
| 复制 | `Ctrl+Shift+C` / `Ctrl+Insert` |
| 粘贴 | `Ctrl+Shift+V` / `Shift+Insert` |

- `Ctrl+C` **保留给中断信号**，不会变成复制——这是肌肉记忆，不能改；
- 多行粘贴会先弹确认并显示前几行，取消后一个字节都不发；
- 粘贴前会把 `\r\n` / `\n` 统一成 `\r`（终端语义）；「去掉行尾空白」默认**关**，
  需要的话在设置里打开——默认改用户粘贴的内容不合适；
- 远端开启 bracketed paste（`?2004`）时，粘贴会被正确包裹，vim 里不会出现 `200~` 字样；
- 右键默认**弹菜单**（复制 / 粘贴 / 全选 / 查找 / 清屏 / 左右分屏），可在设置里改成
  「直接粘贴」——那时用 `Ctrl+右键` 或 `Shift+右键` 唤出菜单。中键直接粘贴。
  万一某个构建里读剪贴板被策略拒绝，会明确提示「请用 `Ctrl+Shift+V`」而不是静默无反应。

## 快捷键可以重绑

底部「键位」→ 每行一个动作 → 点「录制」→ 按新组合键。

- **冲突会被拒绝**，并告诉你被哪个动作占用了；
- 可「恢复默认」、**导出成 JSON 文件**、**从文件导入**（不认识的动作用「跳过 N 项」说出来）；
- 目前可重绑 **32 个动作**：复制、查找、查找上/下一个、放大/缩小/重置字号、关闭查找栏、广播、文件面板、隧道面板、新建本地终端、上/下一个标签、打开设置、键位、左右分屏，以及关闭/复制/重命名当前标签、跳到第 1~3 个标签、清屏、全选、上滚下滚一页与一行、到顶/到底、显示隐藏侧栏；
- 键位存在 `config.toml`。
- 「上/下一个标签」（`Ctrl+Tab` / `Ctrl+Shift+Tab`）按**最近使用**的顺序切换，不是按
  标签从左到右的位置：第一次按回到「上一条用过的」，继续按沿最近顺序往下走，
  停手 1.5 秒后重新排。标签多了以后这一条比按位置切省事得多。

## 多执行广播

底部「广播」打开一条输入栏：一条命令发给**所有已连接会话**。

- 两种模式：「一行一发」「发送前确认」；
- 结果按输出分组：一致就折成「N 台一致：…」，不一致的按组展开并标红，悬停看完整输出；
- **目标可选**：点广播栏的「目标」列出所有已连接标签，勾掉哪个就不发给哪个（默认全部），按钮上写着「目标 2/3」。勾过的标签全关掉会自动退回「全部」；反过来，手动把勾全去掉再发送会明确提示「选中的标签没有已连接的会话」，不会静默改成发给所有人；
- **危险命令**（`rm -rf /`、`mkfs`、`dd of=/dev/`、`shutdown`、fork 炸弹等）无论哪种模式都强制确认，确认框里写明命令原文与目标会话数；
- **可以加自己的规则**：设置 → 终端 →「自定义危险命令规则」，填一个 JSON 字符串数组，比如 `["rm -rf /opt/prod","systemctl stop nginx"]`。写坏的正则**当场报错且不保存**（不会静默失效）；内置那套不可关——那是安全阀，不是配置项；
- **结果可导出 CSV**：表头 `命令,主机,输出`，每台一行；按 RFC 4180 转义并带 UTF-8 BOM，Excel 打开中文不乱码。

### 实时逐键

广播栏里勾「实时逐键」，你在当前终端敲的每个键都会同步到其余已连接会话——适合要逐条看同一段交互的场景（例如一台机器上用 `vim` 改配置，另一台跟着看）。

- 开之前会弹一次确认，说清「没有确认机会」；开着时整条广播栏和底栏「广播」按钮变红；
- **关掉广播栏就等于关掉实时逐键**，不会有「栏收起来了还在往外发」的状态；
- 实时模式下敲出危险命令（`rm -rf /`、`mkfs`、`dd of=/dev/` 等）时，**回车会被拦下**、实时逐键自动关闭并弹出说明——那条命令不会执行。但已经打出去的字符收不回来，这是逐键广播本身的边界；
- 反向不对齐：只把**你在当前终端**的输入发出去，别的会话的输入不会回流给你。

## 标签

| 动作 | 怎么做 |
|---|---|
| 关闭 | 点 `×` 或**中键**点标签 |
| 重命名 | **双击**标签 |
| 复制标签 | 右键标签 →「复制标签」（用同一条连接参数再开一个） |
| 关闭其他 / 关闭右侧 / 关闭全部 | 右键标签 |
| 调整顺序 | 按住左键拖动标签 |

标签栏溢出时横向滚动，不会把每个标签压扁。到「设置 → 外观 → 标签栏位置」可以把标签栏挪到终端下方（底部），位置会记住；拖拽、中键关闭、溢出滚动在两种位置下都一样。

## 鼠标上报

远端程序（vim、tmux、`htop`）开启鼠标模式后，点击/滚动会作为鼠标序列发给远端；按住 `Shift` 点击则强制本地选择文本，不发给远端。

## 查找

`Ctrl+F` 打开查找栏，输入即搜，计数显示 `x/y`；`Esc` 关闭。
