# P0 覆盖与验收状态

对照 [`spec/04-feature-matrix.md`](../spec/04-feature-matrix.md) 的 44 条 P0，逐条标状态与证据。

**状态口径**

| 标记 | 含义 |
|---|---|
| ✅ | 规格要求的能力都在，且有测试盯着 |
| 🟡 | 主链路可用，规格里**明确写了**的某些子项没做（列在「缺什么」） |
| ⬜ | 没做 |

「验收依据」只写可执行的证据：测试文件、e2e 断言、或 `docs/design/15-testing.md` 里的条目。
没有证据的一律标 🟡——**没验过不等于没问题**。
