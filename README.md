| 终端外观与编码（`TER-005` / `TER-006` / `TER-008`） | ✅ 可用 | 底部工具条切换 UTF-8 / GBK / GB18030 / Big5 / Shift-JIS / Latin-1；**切换只影响之后的输出，已显示内容不动**（规格明确要求，省得为了改编码把历史刷掉）。多字节字符跨块用流式解码器拼，不会在分块边界裂开。`UTF-8` 时把字节直接交给 xterm（它自己的增量解码最稳），其它编码才过 `TextDecoder`。**内置 21 套配色**（Solarized / Dracula / Nord / Gruvbox / One Dark / Monokai / Tokyo Night / Catppuccin 等），**可导入 Windows Terminal 的 `schemes` JSON 与 iTerm2 的 `.itermcolors`**（导入的存进 `config.toml`，重启后还在；同名覆盖不攒重复项）、字体族、字号、行高、**回滚行数（默认 10 000，可配到 1 000 000）**全部在底栏可调，改完立刻作用于已开会话并重新 fit；**字体缺失时在设置里写明「本机没有 X，实际用的是 Y」**，选到比例字体时另给一条「不是等宽字体，表格会错位」的警告，不静默回退。偏好写在 `config.toml`（与会话库同目录）：人可读、可进 Git。位置优先级 `--config-dir` > `--portable` > `WT_DATA_DIR` > `%APPDATA%\WindTerm`；`--config-dir` 少了值会直接报错，不会悄悄退回默认目录 |
| 多执行广播（`TER-004`） | ✅ 可用（三种模式） | 底栏「广播」打开一条输入栏：同一命令发给**所有已连接会话**，按输出分组收起——输出一致的折成「N 台一致：…」，不一致的按组展开并标红，鼠标悬停能看每组的完整输出。「一行一发」与「发送前确认」两种模式；**危险命令**（`rm -rf /`、`mkfs`、`dd of=/dev/`、`shutdown`、fork 炸弹等）无论哪种模式都强制弹确认，框里写明命令原文与目标会话数（还有几个未就绪会被跳过）。结果可**导出 CSV**（表头 `命令,主机,输出`，每台一行；按 RFC 4180 转义、带 UTF-8 BOM，Excel 打开中文不乱码）。**实时逐键**（`broadcast-live`）：广播栏里勾「实时逐键」，当前终端的每次按键同步到其余已连接会话。逐键模式没有「发送前确认」的时机，所以用三重保险代替——开之前弹一次说明、开着时整条栏与底栏按钮变警示色、**关掉广播栏即自动失活**（栏收起来了按键还在往外发是最危险的静默失效）。但**回车这一下是扣得住的**：实时广播期间会把当前行攒起来，命中危险模式就吞掉这次回车、自动关闭实时广播并说明原因，所以那条命令不会执行（已经打出去的字符收不回，如实如此）。**可选目标**：广播栏的「目标」浮层列出所有已连接标签，勾掉哪个就不发给哪个（默认全部），按钮上直接写「目标 2/3」；勾过的标签全关掉会自动退回「全部」，而「手动把勾全去掉」则会明确报「选中的标签没有已连接的会话」——不静默改成发给所有人。**危险规则可自定义**（设置 → 终端 → 自定义危险命令规则，填 JSON 字符串数组；写坏的正则当场报错不保存，内置那套不可关）。**尚未做**：按会话树节点 / 整个文件夹选目标、每台显示退出码 |
| 设置中心（`SET-001`） | ✅ 可用（7 个分组） | **两个入口**：左侧树头（与会话无关，没有终端也进得去）与终端底栏。7 组：常规（界面语言、本地终端 shell）/ 外观（字号、行高、标签栏位置）/ 终端（编码、配色、导入配色、字体、回滚行数、右键行为、自定义危险命令规则、双击选词分隔符、粘贴去行尾空白、选中即复制开关与防抖延迟）/ 文件（连上自动开面板、显示隐藏文件、显示列）/ 安全（主密码、密码保存默认值、轮换加密密钥、已知主机）/ 网络（连接超时、keepalive 间隔与最多丢失）/ 高级（配置文件路径、重置偏好）。每项标注**生效范围**、**默认值**与**是否需要重启**。**搜索框**按名字与中英文关键词过滤（搜 `gbk`、`乱码`、`encoding` 都能命中），**命中的字高亮**、结果行首标出**所在分组**，搜不到时给空态提示。控件**只有这一份**——底栏不再重复放同一批控件，避免「两处都能改、状态不一致」 |
| 内嵌文本编辑器（`FIL-011`） | ✅ 可用 | 从「编辑」对话框点「在内嵌编辑器打开」：多标签、行号、滚动同步、Tab 插两空格、`Ctrl+S` 保存、查找上一个/下一个、**替换 / 全部替换（可切正则）**、**按扩展名着色的语法高亮**（vendor 内联 Monaco 0.52.2 的 AMD 版，零构建；加载失败自动退回纯 textarea，编辑功能不受影响；映射 32 种语言）、**编码识别与切换**（自动 UTF-8 → GB18030，可手选 Big5 / Shift-JIS / Latin-1；UTF-8 BOM 原样保留）、**换行符识别与切换**（CRLF/LF，就地转换，不会把 CRLF 文件静默改成 LF）、**列编辑**（顶栏「列选」开关：拖拽即矩形框选，多行同列一起改；也可 `Shift+Alt` 拖拽临时框选）。**大文件保护**：超过 2 MB 直接拒绝并提示改用外部编辑器；既不是 UTF-8 也不像 GBK 的文件同样拒绝（「不猜编码」） |
| 远端文件编辑（`FIL-005`） | ✅ 可用（外部编辑器） | 文件面板选中文件 →「编辑」：下载到下载目录下的 `wt-edit/`，给「用系统程序打开」（Windows `start` / macOS `open` / Linux `xdg-open`）与「写回远端」。**自动检测本地保存**：下载时记下本地副本的修改时间，对话框开着时轮询；外部编辑器一存盘就提示「本地副本已修改，可写回远端」并高亮按钮，关掉对话框立即停轮询。写回前**比一次远端大小**：期间被别人改过就报 `SFTP_CONFLICT` 拒绝覆盖，文件被删则拒绝重建。写回是**原子**的（先写临时文件再 `rename`）——观察者只会看到旧内容或新内容，不会看到空文件；**原文件的权限位会保留**（先把 `SETSTAT` 设到临时文件上再替换，「编辑 755 的脚本存完变 644」不会发生）；服务端不肯覆盖 `rename` 时降级为「先删后改名」，并在状态栏如实说明（不会假装原子）。内嵌编辑器见下一行 |
| 密码保存（`SEC-002`） | ✅ 三态可用 + SFTP 共享连接 | 连接表单里「密码」三选一：**不记住** / **本次记住**（只放本次运行的内存，不落盘、不要主密码，关掉就忘）/ **永久记住**（写进保险库，需要主密码）。选中会话时会自动填入——优先用本次记住的，其次保险库；**自动填入的口令被拒时会提示「可能已过期」并让你重新输入**，连上后覆盖保存。密钥/agent 模式下该控件禁用并收起。只开 `KbdInteractiveAuthentication` 的服务端（`PasswordAuthentication no`）会自动回落到 keyboard-interactive，并在成功后**同样保存密码**——这是 MobaXterm 的已知缺陷。**SFTP 复用同一条已认证连接**（按「用户@主机:端口」，跳板链路不入池）：一次登录之后列目录、下载、改名、改权限都走这条连接，不再每步重新握手。复用能成立的关键是**串行化**——每条连接外面一把异步锁，同一时刻只跑一个请求；早先简单共享 `SftpSession` 会随机卡死，根因就是它取 `&self` 但请求号是共享状态。池上限 16 条、LRU 淘汰；某个请求失败就把那条连接摘掉，下次重连。`sftp_pool_stats` 可读 `{pooled, opens, reuses}`，`WT_SFTP_NO_POOL=1` 回退到「每次新建」 |
| 主密码管理（`SEC-001`） | ✅ 可用 | 设置里「主密码」：改主密码（旧密码解封校验 → 新密码重封 → 写盘，**保险库内容不变**；新口令同样过强度检查——改密码时把口令改弱是最容易忽略的降级）、移除保险库（二次确认，文案写明所有密码会没且不可恢复）。之前只有「创建/解锁/锁定」，用户想起换主密码没有任何入口 |
| 已知主机（`SEC-005`） | ✅ 可用 | 设置里「已知主机」列出每条记录的**主机模式 + 算法 + SHA256 指纹**，可逐条「忘记」——下次连接重新走 TOFU。**密钥变了会直接阻断连接**并把新旧指纹一起摆出来（不再当成「未知主机」自动信任——那等于把已信任的指纹换成对方给的，等于接受中间人），要重置信任就在这个列表里「忘记」再连。之前遇到 `SSH_HOSTKEY_CHANGED` 只能手改 `known_hosts`，而那里存的是 base64 blob，手改几乎必然改坏。删除按**模式**匹配，所以哈希形式（`|1|salt|hmac`）与通配符也能删 |
| SSH 密钥生成器（`LOC-014`） | ✅ 可用 | 底栏「密钥」：选 ed25519 / RSA 3072 / ECDSA P-256 生成，**可选口令加密**（口令不给就落明文私钥，界面上写明「已加密」与否）；生成后同时给出 SHA256 指纹、可贴进 `authorized_keys` 的公钥行与私钥落盘路径（下载目录，名字冲突自动加序号）。「导入已有密钥」读文件后只显示算法与指纹——**私钥内容不回传界面**。测试与生产的生成走同一条 `wt_ssh::generate_key`，不再各写一份 |

## 这是什么

MobaXterm 是 Windows 上最受欢迎的远程运维工具箱，但它有三个无法回避的限制：**仅支持 Windows**、**闭源**、**免费版限制较多（会话数、隧道数、宏等）**。

WindTerm 的目标是把它完整地重做一遍，并补上它没有的东西：

| 维度 | MobaXterm | WindTerm |
|---|---|---|
| 平台 | 仅 Windows | Windows / macOS / Linux 三平台同源 |
| 许可 | 闭源（免费版受限） | Apache-2.0，代码可审计、可自建 |
| 会话 | INI 文件，弱结构 | SQLite + 结构化模型，可查询、可同步、可审计 |
| 终端 | PuTTY 内核 | 可插拔 VT 内核（xterm.js → 自研 Rust 内核的可迁移路径） |
| 扩展 | `.mxt3` 插件（只装二进制） | 带签名与权限清单的插件包 + 包管理器 |
| 自动化 | 宏录制 | 宏录制 + 可脚本化 CLI + 无头模式 |
| 安全 | 主密码 | 主密码 + Argon2id/AEAD 保险库 + OS 钥匙串 + 审计日志 |
| 数据外发 | 无 | 无遥测，默认完全离线 |

功能覆盖的判定标准不是「像不像 MobaXterm」，而是 **MobaXterm 用户能否在不损失工作流的前提下整体迁移过来**。
逐条对照见 [`docs/spec/04-feature-matrix.md`](docs/spec/04-feature-matrix.md)。
